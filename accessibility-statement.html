Declaração de Acessibilidade

Última atualização: 15 de Janeiro de 2025
Versão: 1.0

1. Compromisso com a Acessibilidade

João Lobo Advogados está comprometido em garantir a acessibilidade digital para pessoas com deficiência. Estamos continuamente a melhorar a experiência do utilizador para todos e aplicando os padrões de acessibilidade relevantes.

2. Medidas para Apoiar a Acessibilidade

Tomamos as seguintes medidas para garantir a acessibilidade do nosso website:

  • Incluímos acessibilidade como parte da nossa missão
  • Integramos a acessibilidade nas nossas políticas internas
  • Nomeamos um responsável pela acessibilidade
  • Fornecemos formação contínua à nossa equipa
  • Incluímos pessoas com deficiência na nossa equipa de testes
  • Realizamos auditorias de acessibilidade regulares

3. Estado de Conformidade

Este website está em conformidade parcial com as Web Content Accessibility Guidelines (WCAG) 2.1 nível AA.

Conformidade parcial significa que algumas partes do conteúdo não estão totalmente em conformidade com o padrão de acessibilidade.

4. Conteúdo Não Acessível

4.1 Problemas Conhecidos

As seguintes áreas podem não estar totalmente acessíveis:

Imagens

Algumas imagens históricas podem não ter texto alternativo adequado

Ação: Estamos a adicionar descrições apropriadas

Documentos PDF

Alguns documentos PDF antigos podem não ser acessíveis

Ação: Estamos a converter documentos para formatos acessíveis

Vídeos

Alguns vídeos podem não ter legendas ou transcrições

Ação: Adicionaremos legendas a todos os novos vídeos

Formulários

Alguns formulários complexos podem ser difíceis de navegar com teclado

Ação: Melhorias em andamento

5. Funcionalidades de Acessibilidade

5.1 Navegação por Teclado

Todo o website é navegável usando apenas o teclado:

  • Tab: Navegar para a frente
  • Shift + Tab: Navegar para trás
  • Enter: Ativar links e botões
  • Esc: Fechar modais e menus

5.2 Leitores de Ecrã

O website é compatível com os principais leitores de ecrã:

  • JAWS (Windows)
  • NVDA (Windows)
  • VoiceOver (macOS, iOS)
  • TalkBack (Android)

5.3 Contraste de Cores

  • Ratio de contraste mínimo de 4.5:1 para texto normal
  • Ratio de contraste mínimo de 3:1 para texto grande
  • Suporte para modo de alto contraste

5.4 Ampliação de Texto

O texto pode ser ampliado até 200% sem perda de funcionalidade:

  • Ctrl + "+" (Windows) / Cmd + "+" (Mac): Aumentar
  • Ctrl + "-" (Windows) / Cmd + "-" (Mac): Diminuir
  • Ctrl + 0 (Windows) / Cmd + 0 (Mac): Restaurar

5.5 Estrutura Semântica

  • Uso apropriado de headings (h1-h6)
  • Landmarks ARIA para navegação
  • Listas e tabelas com marcação adequada
  • Formulários com labels associados

6.1 Como Reportar Problemas

  2. Telefone: +351 915 964 547

Forneça as seguintes informações:

  • Descrição do problema
  • Navegador e tecnologia assistiva utilizados
  • Sistema operativo

6.2 Tempo de Resposta

Esperamos responder ao seu feedback em:

  • Reconhecimento inicial: 2 dias úteis
  • Análise completa: 7 dias úteis
  • Resolução (quando possível): 30 dias

6.3 Pedidos de Formato Alternativo

Se precisar de informações neste website num formato alternativo:

  • Documentos em braille
  • Áudio
  • Impressão em letra grande
  • Formato acessível (DOCX, TXT)

Contacte-nos e forneceremos o conteúdo no formato solicitado no prazo de 10 dias úteis.

7. Plano de Melhoria Contínua

7.1 Objetivos de Curto Prazo (3 meses)

  • Adicionar texto alternativo a todas as imagens
  • Melhorar contraste em todos os elementos
  • Corrigir problemas de navegação por teclado

7.2 Objetivos de Médio Prazo (6 meses)

  • Converter todos os PDFs para formato acessível
  • Adicionar legendas a todos os vídeos
  • Implementar skip navigation melhorado

7.3 Objetivos de Longo Prazo (12 meses)

  • Alcançar conformidade total WCAG 2.1 AA
  • Implementar testes automatizados contínuos
  • Criar guia de acessibilidade interno

8. Legislação Aplicável

Esta declaração de acessibilidade está em conformidade com:

  • Diretiva (UE) 2016/2102 do Parlamento Europeu
  • Decreto-Lei n.º 83/2018 (transpõe a diretiva para Portugal)
  • WCAG 2.1 nível AA (padrão internacional)
